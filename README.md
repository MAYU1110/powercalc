# PowerCalc
**电力电子电路参数自动计算工具 | 前端在线计算平台**

## 项目介绍
PowerCalc 是一款专为**电子信息、电力电子、自动化、电路设计工程师与学生**打造的在线电路计算工具。
无需安装软件，无需复杂配置，在浏览器中即可完成电路拓扑设计、参数计算、单位换算等高频工作，快速获得理论设计值，提升开发与学习效率。

## 项目目的
1. 为电源、电力电子从业者提供轻量化、免费、开源的在线计算工具
2. 简化传统电路手动计算流程，实现「参数输入 → 一键计算 → 自动输出结果」的高效闭环
3. 帮助工程师快速验证拓扑方案，减少手动计算错误，节省设计时间
4. 采用模块化架构，便于后续扩展更多电路拓扑与实用工具

## 核心功能模块
PowerCalc 目前包含三大核心工具模块，覆盖电路设计全流程需求：

### 1. 电路拓扑设计模块（核心模块）
- 支持选择经典 DC-DC 等电力电子拓扑，自动显示标准拓扑结构图
- 支持输入电路需求参数：输入电压、输出电压、额定功率、开关频率、效率、纹波系数等
- 核心功能：网页端直接输入参数，一键自动计算并输出占空比、电感值、电容值、电流应力、纹波电流等理论设计值
- 纯前端实时计算，无后端依赖，打开即用

### 2. 功率计算模块
支持电气功率相关快速计算，适用于电路设计前期方案估算与参数验证。

### 3. 单位换算模块
提供电压、电流、电阻、功率、频率等常用电气单位一键换算，解决工程计算单位统一问题。

## 产品特点
- 🚀 开箱即用：浏览器直接运行，无需下载、无需安装
- ⚡ 一键计算：参数输入 → 点击设计 → 自动输出理论计算结果
- 🎨 专业界面：深色护眼模式 + 玻璃拟态设计，简洁专业
- 🔧 模块化架构：新增电路拓扑仅需添加独立文件，不修改原有代码
- 🆓 开源免费：纯前端开源，支持本地运行与二次开发
